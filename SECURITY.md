# Security policy

The current release candidate is the only supported version.

Report a vulnerability to `qubitcoin@superquantum.com`, or use GitHub private vulnerability
reporting when it is available. Do not open a public issue for a suspected vulnerability. Include
the affected version, impact, reproduction steps and any proposed mitigation.

The maintainers aim to acknowledge reports within three business days. A fix or status update will
follow after the report has been reproduced and assessed.

Resource-limit requests and unsupported input types are not vulnerabilities unless they bypass a
documented limit or cause behavior outside the documented contract.
